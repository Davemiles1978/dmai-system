One-Click Installer

Autonomous Intelligence System  ·  Full production setup

v6.0.0
1
Prerequisites Check Checking…

Verifying that Python 3.11+, pip, and git are installed on your machine.

⏳Python 3.11+checking…
⏳pipchecking…
⏳gitchecking…
⏳Port 5000 availablechecking…

Missing prerequisites? Open Terminal and run:

brew install python@3.11 git

No Homebrew? Install at brew.sh

2
Repository Setup Waiting

Clone the DMAI repository to your Mac, or update an existing copy.

Run this in Terminal:

git clone https://github.com/Davemiles1978/dmai-system.git ~/dmai-system
3
API Keys & Configuration Waiting

Fill in your API keys. All values are saved only to your local .env file — never sent anywhere.

Need a free PostgreSQL DB? Neon.tech or Railway.app offer free tiers.

Add at least one AI provider key. More providers = more fallback options and capabilities.

4
Install Dependencies Waiting

Creates a Python virtual environment and installs all required packages.

Run these commands in Terminal inside your install directory:

cd ~/dmai-system python3.11 -m venv .venv source .venv/bin/activate pip install --upgrade pip pip install -r requirements.txt pip install -r requirements_training.txt

This takes 2–4 minutes on first run. You'll see packages installing.

Then run the pre-flight checker to confirm everything is ready:

python scripts/check_ready.py
5
Launch DMAI Waiting

Choose how you want to run DMAI. You can change this at any time.

💻

Local — Foreground

Start in Terminal. Ctrl+C to stop. Best for development and testing.

⚙️

Local — Background

Runs silently in background. Starts automatically on Mac login via launchd.

☁️

Deploy to Render

Production cloud deployment. Free tier available. Always-on, public URL.

🐳

Docker

Containerised deployment. Requires Docker Desktop on Mac.

Run in Terminal:

cd ~/dmai-system && source .venv/bin/activate && python dmai_core_complete.py
🟢

DMAI is Running

Your autonomous intelligence system is live. Open the dashboard to monitor and control everything.

📊 Dashboard ⚡ API Status 🧠 AI Training 🤖 SI Training ♾️ Kaizen 🔐 Admin

Logs: tail -f ~/dmai-system/dmai.log
Stop: Ctrl+C (foreground) or launchctl stop com.dmai.system (background)
